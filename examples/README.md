# Examples

Run a server with `cargo run --release -p <example>`, then connect with `gsh localhost --insecure`.

| Example | Demonstrates |
| --- | --- |
| [Password](password_auth/) | Password authentication |
| [Signature](signature_auth/) | Public-key authentication |
| [Cube](cube/) | Software 3D rendering and resizing |
| [Colors](colors/) | Input events and two fixed-size windows |
| [Liquid simulation](liquid_sim/) | Parallel particle simulation and compressed frames |
| [Remote desktop](remote_desktop/) | Primary-monitor capture and compressed streaming |
